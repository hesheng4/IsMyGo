# 创新点说明

> 本文档从 architecture.md 的「创新点」小节独立拆出并补充；
> 完整论证见 architecture.md §3、§8。

## 1. 相对 FARS 局限的三项定向优化

1. **实验真实性**：以真实 LLM（答题+摘要双环）替代 FARS 常见的仿真评测，
   逐题流水含 token/延迟，全部论文数字由 `analyze.py` 从流水生成
   （零手工转录；复现性对账脚本 `_d3_audit.py` 验证 8,359/8,359 条记录
   与原始缓存一致）。
2. **资源效率**：单篇论文实验总消耗 ≈ 2.47 千万 token，较 FARS 的
   1.14 亿 token/篇低约 4.6 倍；断点缓存使任何中断零浪费重跑。
3. **统计严格性**：按题配对 bootstrap 95% CI + 精确 McNemar
   （双基线：主对照 BM25 + 最强替代），四档预算全部显著的负结果也
   如实报告（论文 §Negative Results，N1–N6）。

## 2. 修订轮新增的方法学创新（预注册协议）

4. **预注册判据的负结果研究范式**：修订轮实验（结构化压缩器 KV/EDU、
   重排器、judge 全量扩容）在 `ANALYSIS_PROTOCOL.md` 中先锁判据后跑
   实验（lock 2026-08-24），结论措辞由预注册三档规则决定，杜绝
   事后挑显著（HARKing）。
5. **排名-读取解耦诊断**：固定预算下用交叉编码器重排器把离线
   Recall@5 从 0.834 推到 0.954 而在线答题不动（p=1.0），
   以最小干预分离「检索排名」与「读取侧天花板」两个失败源。
6. **双口径披露机制**：provider 内容审核拒答（4/120 题）按 0 计分
   保留 + 敏感性口径（排除后 n=116）并列报告，两口径结论一致才下判读。

## 3. 框架级创新（贡献回上游）

7. **paper_guard 双 Rail**：幻觉校验（量化断言 vs results.json 溯源）
   与学术格式校验（章节完整性/引用对齐）作为框架级能力挂载到每个
   团队成员，配置门控默认关闭（详见 framework_contribution.md）。
8. **research_tools 工具集**：DeepSearch 文献检索与 LongMemEval 评测
   收编为框架工具 provider，子进程隔离、报告落盘，形成
   「检索可溯源 → 断言可比对」闭环。
