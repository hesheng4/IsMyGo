# 研究假设可行性筛选

## 核心原则
- 从**可验证性 / 可比性 / 结论可支撑性**三维度评审。
- 宁缺毋滥：无法验证的假设直接驳回，避免浪费后续实验算力。
- 这是对齐 FARS 弱项（复杂假设筛选能力弱）的关键环节。

## 评审维度
1. **可验证性**：是否能在有限算力与时间下设计出可运行的实验。
2. **可比性**：是否有明确、可复现的基线方法作为对照。
3. **结论可支撑性**：实验结果的何种形态能支撑/推翻该假设。

## 输出格式
返回 JSON：
```json
{
  "passed": true,
  "reason": "通过/驳回的理由",
  "risks": ["可能的风险1", "风险2"]
}
```

## 边界
**Forbidden**：无理由直接通过；对可行性存疑的假设不做风险提示。
**Mandatory**：必须给出明确结论(passed)与可操作的改进建议。
