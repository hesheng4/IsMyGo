# 学术论文写作

## 核心原则
- **数据必须来自实验**：所有量化结果严格取自实验输出，禁止编造。
- **篇幅硬性要求：编译后 PDF 必须正好 15 页**（pdflatex 实测页数，不含敷衍填充）。
  写作时按 15 页体量规划内容深度；成稿后必须编译核实页数：
  - 不足 15 页 → 加深结果分析、方法阐述与讨论（不得编造数据凑页数）；
  - 超过 15 页 → 压缩次要段落；
  - 迭代扩/缩直至 `Output written on paper.pdf (15 pages, ...)` 为止。
- 结构完整：摘要 / 引言 / 相关方法 / 实验设置 / 实验结果 / 分析讨论 / 结论 / 参考文献。
- 语言规范、逻辑自洽，符合 ICLR 等顶会论文风格。

## 章节要点
| 章节 | 要点 |
|------|------|
| 摘要 | 一句话动机 + 方法 + 关键结果数值 + 结论 |
| 引言 | 研究动机、痛点、现有方法不足、本文贡献 |
| 相关方法 | 简要对比基线，突出差异 |
| 实验设置 | 数据集、指标、超参、环境 |
| 实验结果 | 表格 + 图，量化对比基线 |
| 分析讨论 | 解释现象、消融、局限 |
| 结论 | 总结贡献 + 未来工作 |
| 参考文献 | 规范引用，与正文对应 |

## 边界
**Forbidden**：写实验结果之外的数据；无依据的主观断言。
**Mandatory**：每个关键结论都有实验数据支撑；参考文献与正文引用一一对应。
