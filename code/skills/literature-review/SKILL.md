# 文献检索与研究现状梳理

## 核心原则
- 以**最新、权威**文献为准（优先 arXiv、顶会/顶刊），标注来源与年份。
- 输出必须**结构化**：研究痛点、现有方法、仍未解决的空白(open gap)。
- 不做无依据的综述，每条结论尽量给出对应文献。

## 输出格式
返回 JSON：
```json
{
  "pain_points": ["痛点1", "痛点2"],
  "existing_methods": ["方法1"],
  "open_gaps": ["仍未解决的空白"],
  "references": ["作者/标题/年份/来源"]
}
```

## 边界
**Forbidden**：编造不存在的文献；泛泛而谈而不给来源。
**Mandatory**：至少给出 3 篇可追溯的关键文献；明确区分"已解决"与"未解决"。
